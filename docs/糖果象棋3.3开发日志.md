# 糖果象棋 V3.3 开发日志

**版本定位：互联网对战正式上云后的第一个版本**
**技术栈：Qt 6.8.3 (MinGW 13.1) C++ 客户端 + Node.js (Express + WebSocket + SQLite) 服务端**

> 说明：3.2 及更早版本的开发日志（`糖果象棋3.2开发日志.md`）记录了当时的逐日时间线；
> 本篇为 V3.3 的版本开发记录，按「更新内容 / 工程与部署 / 发布与材料」三部分整理。

## 一、本次更新内容（相对 3.2）

### 1. 对局中私信免打扰

**问题**：3.2 及以前，对局进行中收到好友私信会直接弹出聊天窗口，正在思考棋路时被
打断，体验很差。

**改法**：对局期间收到私信不再弹窗，改为在「好友」按钮上亮红点提示；消息记录服务端
照常入库，玩家打完这一局回到主菜单后再查看即可。

- 涉及客户端：`MainWindow`（对局中消息分流）、`StartScreen`（红点徽章刷新）
- 涉及服务端：`realtime.js`、`routes/friends.js`（离线消息存储与拉取）

### 2. 版本握手校验

**问题**：客户端连服务器只认协议，不认版本。老客户端连上新服务端时，个别新增协议
字段对不上，会出现对战异常却难以定位。

**改法**：客户端登录时与服务端核对版本号，版本不匹配时给出明确提示，避免"能连上但
打不了"的隐性故障。

### 3. 全端发布下载站

Windows 安装包、安卓 APK、源代码三件套统一发布：

- 下载站：http://118.31.237.140:3000 （公网，固定 IP）
- Gitee Release：永久有效的备用下载地址

## 二、工程与部署

### 1. 互联网模式正式上云

- 服务端从本地 + cpolar 内网穿透，迁移到**阿里云 ECS**，公网地址固定为
  `http://118.31.237.140:3000`，不再受内网穿透域名漂移影响。
- 服务端为 Node.js + Express + WebSocket + SQLite（内置库，无需独立部署数据库），
  资源占用很轻，一台低配云服务器即可承载。
- 关键点：安全组放行 3000 端口；服务端进程需做**开机自启**（见 `tools/`
  下的启动脚本），避免重启服务器后服务掉线。
- 客户端侧连接地址统一写在 `gui/ServerConfig.h`，公网/本地切换只改这一处。

### 2. 客户端打包

- Windows：Inno Setup 6，脚本 `setup.iss`，把 `dist/` 下已用 `windeployqt` 补齐
  的 Qt 运行库（Qt6Core/Gui/Widgets/Network/WebSockets/Multimedia 等 DLL、
  platforms/imageformats 插件）一并打进安装包。
- 安卓：`gui/build-android.ps1` + androiddeployqt 产出 arm64 APK。

### 3. 源码包结构

发布用的源码压缩包只含 **`gui/`（客户端）+ `setup.iss`**，与服务端分开管理，
方便别人只取客户端部分。
