# Candy-Chess Version 3.3 Release Notes

Welcome to download Candy-Chess Version 3.3! The first release after the online
server moved to the cloud.

## Update Log

- **Do-not-disturb DMs in game:** during a match, incoming friend messages no
  longer pop up and interrupt you — only a red badge on the "Friends" button.
  Read them after you return to the main menu.
- **Version handshake check:** the client verifies its version with the server
  at login, preventing abnormal games caused by an outdated client.
- **Full download site online:** Windows installer / Android APK / source code
  are available on the download site and Gitee Release (permanently valid).

The Internet-mode server is now officially hosted on Alibaba Cloud with a fixed
public address: http://118.31.237.140:3000
(The old cpolar tunnel URL changed after every restart — now the IP is fixed.)

## How to Play

Simply open the installer and follow the setup steps to start playing.
For LAN games, click "Online" — one player creates a room, the other joins.
For Internet games, click "Internet Mode", register an account and add friends.
